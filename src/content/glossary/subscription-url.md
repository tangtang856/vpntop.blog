当你购买完机场套餐后，后台往往会提供一个形如 `https://airport-sub.example/sub?token=xxxxxx` 的神秘网址，被称为 **“订阅链接”（Subscription URL）**。

初学者往往感到好奇：这个链接到底是用来做什么的？为什么不能把它当成普通网页直接在浏览器打开？

---

## 一、订阅链接的工作原理

在早期的代理工具中，如果你购买了一个拥有 30 个节点的机场，你必须手动将每一个节点的 IP 地址、端口、密码、加密方式逐条输入到软件中。一旦服务商因为服务器维护更换了 IP，所有用户必须全部重新手动修改。

**“订阅链接”的诞生彻底解决了这个痛点**：
- 订阅链接本质上是一个带有专属安全密钥（Token）的 API 接口；
- 当客户端（如 Clash Verge、小火箭）访问该链接时，服务器会以加密或 YAML/Base64 格式返回该账户所属的 **全部最新节点列表、连接参数、到期时间以及已用流量**；
- 每次客户端执行“更新订阅”，就会自动同步最新的可用节点，用户完全无需关心后端 IP 的更替。

## 二、主流订阅格式

| 格式名称 | 适用客户端 | 特点 |
| :--- | :--- | :--- |
| **Clash / Meta 配置** | Clash Verge, Clash Meta, OpenClash | 包含完整的智能分流策略组与规则 |
| **Shadowrocket 格式** | iOS 小火箭 (Shadowrocket) | 轻量 URL 列表，导入极速 |
| **V2Ray / VLESS 格式** | v2rayNG, Sing-box (通过转换) | 标准 Base64 编码的节点单项链接 |
| **通用聚合订阅** | Subconverter 自动在线转换 | 可将任意订阅转换为目标软件格式 |

---

## 三、极其重要的安全防泄露警示

> **严正警示**：你的订阅链接相当于你的 **账户提款卡与网络身份证**！任何人只要获取了你的订阅链接 URL，就可以将其导入他自己的客户端，**不仅会随意盗刷你的套餐流量，还可能导致你的账号因“多地异地 IP 共享滥用”被机场系统自动封禁并不予退款**！

### 防泄露三原则：
1. **切勿在公开群聊、论坛或贴吧截图中暴露完整 URL**；
2. **切勿使用不可信的第三方公共“在线订阅转换工具”**（部分黑心站长会在后台恶意收集用户 Token 盗刷流量）；
3. **若不慎泄露**，请立即前往机场控制台，点击 **“重置订阅链接 / 重置 Token”**，即可使之前的旧链接瞬间失效。
