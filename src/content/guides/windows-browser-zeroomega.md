## 一、前期环境准备与工具清单

在开始配置前，请确保具备以下基础设施准备：

1. **稳定的网络代理节点支持**：建议优先选择经过本站核验的真实内网专线服务商（如 [微风网络 Breezenet](/review/breezenet/)、[暮光网络](/review/muguang/) 或 [隐形人](/review/yinxingren/)），避免使用已被 GFW 大面积阻断的廉价小作坊。
2. **最新客户端软件包**：建议直接通过 GitHub 官方 Releases 仓库或正规应用商店获取纯净安装包，切勿下载第三方破解版或二次打包的高危木马版本。
3. **已激活的通用订阅链接**：确保机场控制台处于正常服务期内，剩余可用流量充裕。

## 二、图文保姆级操作步骤详解

### 第 1 步：在 Edge 或 Chrome 应用商店搜索安装 ZeroOmega 扩展插件

在 Edge 或 Chrome 应用商店搜索安装 ZeroOmega 扩展插件。在执行此步骤时，请留意系统是否弹出安全授权请求。对于虚拟网卡模式（TUN），必须赋予对应的管理员网络配置特权才能正常启动。

### 第 2 步：打开插件选项，新建情景模式并命名为“代理模式”，类型选择“代理服务器”

打开插件选项，新建情景模式并命名为“代理模式”，类型选择“代理服务器”。在执行此步骤时，请留意系统是否弹出安全授权请求。对于虚拟网卡模式（TUN），必须赋予对应的管理员网络配置特权才能正常启动。

### 第 3 步：代理协议选择 SOCKS5，代理服务器填入 127.0.0.1，端口填入本地客户端端口

代理协议选择 SOCKS5，代理服务器填入 127.0.0.1，端口填入本地客户端端口（如 7890）。在执行此步骤时，请留意系统是否弹出安全授权请求。对于虚拟网卡模式（TUN），必须赋予对应的管理员网络配置特权才能正常启动。

### 第 4 步：新建“自动切换”情景模式，规则列表规则填入 GFWList 在线规则地址

新建“自动切换”情景模式，规则列表规则填入 GFWList 在线规则地址。在执行此步骤时，请留意系统是否弹出安全授权请求。对于虚拟网卡模式（TUN），必须赋予对应的管理员网络配置特权才能正常启动。

### 第 5 步：在浏览器右上角插件图标处将活动模式勾选为“自动切换”，即可实现访问谷歌走代理、访问百度走直连

在浏览器右上角插件图标处将活动模式勾选为“自动切换”，即可实现访问谷歌走代理、访问百度走直连。在执行此步骤时，请留意系统是否弹出安全授权请求。对于虚拟网卡模式（TUN），必须赋予对应的管理员网络配置特权才能正常启动。

## 四、常见问题解答与故障排错 (FAQ)

### Q: SwitchyOmega 在新版 Chrome 上提示不支持清单 V3 怎么办？

**A**: 使用开源社区推荐的现代分支 ZeroOmega，完全兼容 Chrome Manifest V3 规范。

### Q: 这种方式能让电脑上的 Discord 或 Telegram 走代理吗？

**A**: 不能。浏览器插件仅接管浏览器标签页内网页流量，独立桌面客户端需在客户端内设置 Socks5 代理。
