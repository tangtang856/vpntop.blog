在 Windows 电脑上使用机场节点进行科学上网，目前主流推荐的两款开源现代客户端是 **Clash Verge Rev**（基于 Clash.Meta / Mihomo 内核，界面现代且支持多语言）和 **Sing-box**（通用规则代理工具，内存占用极低）。

本文将以目前最为普及、兼容性最好的 **Clash Verge Rev** 为例，提供从零开始的完整图文配置指南。

---

## 一、前期准备工作

在开始配置前，请确保你已经准备好以下两项：

1. **一套可用的机场订阅链接**：可前往 [综合实力排行榜](/ranking/overall/) 选择适合你的机场服务，在用户后台复制你的专属订阅链接（通常为 Clash 订阅格式）。
2. **下载 Clash Verge Rev 客户端**：
   - 官方开源发布地址：GitHub Releases
   - 支持架构：推荐下载 `Clash.Verge_x64-setup.exe`（适用于绝大多数 64 位 Intel/AMD Windows 10/11 电脑）。

> **安全提示**：请务必从官方 GitHub 仓库下载客户端安装包，切勿在来路不明的第三方网盘或破解站下载，以防被植入木马窃取订阅或个人隐私。

## 二、Clash Verge Rev 详细配置步骤

### 步骤 1：安装并启动客户端

双击下载好的安装包，按照向导完成安装。初次启动可能会弹出 Windows Defender 防火墙权限提示，请勾选“专用网络”并点击“允许访问”。

### 步骤 2：切换中文界面（可选）

如果启动后默认显示英文，点击左侧菜单栏底部的 **Settings（设置）** -> **Verge Settings** -> 将 **Language** 修改为 **简体中文** 即可。

### 步骤 3：导入机场订阅链接

1. 点击左侧菜单栏的 **订阅（Profiles）**。
2. 在顶部的输入框中，粘贴你从机场后台复制的 **Clash 订阅链接**。
3. 点击右侧的 **导入（Import）** 按钮。
4. 导入成功后，列表中会出现该机场的配置卡片，**单击选中** 该配置（选中后卡片边缘通常会高亮显示）。

### 步骤 4：测试节点延迟并选择节点

1. 点击左侧菜单栏的 **代理（Proxies）**。
2. 顶部切换到 **规则（Rule）** 模式（推荐日常使用规则模式，国内网站直连不消耗流量，外网自动走代理节点）。
3. 点击右上角的“闪电”或“WiFi”图标进行节点测速。
4. 选择一个延迟低且状态绿色的节点（例如香港、日本或新加坡节点）。

### 步骤 5：启动系统代理

回到左侧菜单的 **设置** 界面，打开 **系统代理（System Proxy）** 开关。此时打开浏览器访问 Google 或 YouTube，即可顺畅加载。

## 三、进阶设置：开启 TUN 模式（推荐）

很多桌面软件（如游戏平台、Telegram 桌面版、部分命令行工具或微软商店）默认不走常规的 HTTP 系统代理。开启 TUN 模式可以将所有软件的网络流量虚拟化劫持到代理内核。

1. 在 Clash Verge 设置中，找到 **服务模式（Service Mode）** 并点击其右侧的安装（Install）。
2. 安装成功后，将 **TUN 模式（TUN Mode）** 的开关拨到打开状态。
3. 此时所有软件的流量都会严格遵照规则分流，彻底杜绝部分软件无法翻墙的烦恼。

## 四、常见报错与排查排障

### 1. 导入订阅提示“网络超时”或“解析错误”
- **原因**：部分宽带网络对机场原订阅域名存在 DNS 污染。
- **解决方法**：开启临时热点或使用备用直连节点尝试刷新，或者登录机场后台转换订阅链接为不同的分流格式。

### 2. 网页能打开，但微信/钉钉断网或提示离线
- **原因**：误选了“全局（Global）”代理模式，导致国内聊天软件也尝试通过境外节点通信。
- **解决方法**：将代理模式切换为 **规则（Rule）** 模式。

### 3. 系统时间不同步导致握手失败
- **原因**：现代加密协议（如 TLS/VLESS/Hysteria2）对系统时间精度要求极高，误差超过 60 秒将直接拒绝连接。
- **解决方法**：进入 Windows“日期和时间”设置，点击“立即同步”以对齐网络时间。
