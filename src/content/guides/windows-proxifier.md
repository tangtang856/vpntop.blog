在开始配置前，请确保具备以下基础设施准备：

1. **稳定的网络代理节点支持**：建议优先选择经过本站核验的真实内网专线服务商（如 [微风网络 Breezenet](/review/breezenet/)、[暮光网络](/review/muguang/) 或 [隐形人](/review/yinxingren/)），避免使用已被 GFW 大面积阻断的廉价小作坊。

3. **已激活的通用订阅链接**：确保机场控制台处于正常服务期内，剩余可用流量充裕。

## 二、图文保姆级操作步骤详解

### 第 1 步：下载并安装 Proxifier 客户端，准备好本地 Socks5 监听端口

下载并安装 Proxifier 客户端，准备好本地 Socks5 监听端口（如 127.0.0.1:7890）。在执行此步骤时，请留意系统是否弹出安全授权请求。对于虚拟网卡模式（TUN），必须赋予对应的管理员网络配置特权才能正常启动。

### 第 2 步：在 Proxifier 中点击 Profile -> Proxy Servers，添加本地代理端口并点击 Check 测试通信

在 Proxifier 中点击 Profile -> Proxy Servers，添加本地代理端口并点击 Check 测试通信。在执行此步骤时，请留意系统是否弹出安全授权请求。对于虚拟网卡模式（TUN），必须赋予对应的管理员网络配置特权才能正常启动。

### 第 3 步：点击 Profile -> Proxification Rules，点击 Add 新增自定义进程分流规则

点击 Profile -> Proxification Rules，点击 Add 新增自定义进程分流规则。在执行此步骤时，请留意系统是否弹出安全授权请求。对于虚拟网卡模式（TUN），必须赋予对应的管理员网络配置特权才能正常启动。

### 第 4 步：在 Applications 中填入游戏主进程名称

在 Applications 中填入游戏主进程名称（如 game.exe; steam.exe）。在执行此步骤时，请留意系统是否弹出安全授权请求。对于虚拟网卡模式（TUN），必须赋予对应的管理员网络配置特权才能正常启动。

### 第 5 步：将 Action 设定为刚才添加的代理服务器，点击 OK 即可完成定向加速

将 Action 设定为刚才添加的代理服务器，点击 OK 即可完成定向加速。在执行此步骤时，请留意系统是否弹出安全授权请求。对于虚拟网卡模式（TUN），必须赋予对应的管理员网络配置特权才能正常启动。

## 四、常见问题解答与故障排错 (FAQ)

### Q: 为什么 Proxifier 偶尔会导致局域网打印机打不开？

**A**: 在 Rules 中确保默认的“Localhost”规则位于最上方并处于 Direct 直连放行状态即可。

### Q: 玩外服联机游戏推荐选什么节点？

**A**: 推荐选择闪跃 FlashLeap 或隐形人的 IPLC 纯专线，其延迟几乎等于物理光纤物理延迟，无抖动丢包。
