安卓手机由于其开源与开放的特性，拥有非常丰富的翻墙代理客户端选择。目前最主流且体验良好的两款客户端是：

1. **v2rayNG**：轻量级、协议兼容广泛（支持 VLESS、Trojan、Shadowsocks 等），操作直观，非常适合单节点使用或新手用户。
2. **Clash Meta for Android (或 Flclash / Surfboard)**：支持强大的自动化策略组分流、节点自动故障转移以及规则分流。

本文将以新手接受度最高的 **v2rayNG** 与功能最全面的 **Clash Meta (Flclash)** 进行双重解析。

---

## 方案一：使用 v2rayNG 快速配置

### 步骤 1：下载安装包
前往 GitHub 官方 Releases 页面下载 `v2rayNG_x.x.x_arm64-v8a.apk`，安装到手机上并授权网络权限。

### 步骤 2：添加机场订阅分组
1. 打开 v2rayNG，点击左上角的“三条杠”侧边栏菜单。
2. 选择 **订阅分组设置**。
3. 点击右上角的 **“+”** 加号新建分组。
4. 填写备注名称（如“我的机场”），在“可选地址 (url)”一栏中粘贴从机场后台复制的 **V2Ray / VLESS 订阅链接**。
5. 点击右上角“对勾”保存。

### 步骤 3：更新并拉取节点列表
1. 返回到主界面，点击右上角的三点菜单图标。
2. 选择 **更新订阅**。
3. 稍等片刻，手机界面上便会刷新出香港、日本、美国等全部可用节点。

### 步骤 4：分流设置与连接
1. 打开侧边栏的 **设置**。
2. 找到 **路由设置** -> 选择 **绕过局域网及大陆地址**（确保国内微信、淘宝不走代理）。
3. 回到主界面，轻点选中你想要使用的节点（选中后左侧通常有绿色或蓝色竖条标识）。
4. 点击右下角圆形的 **V** 图标启动代理。首次连接系统会弹出“网络连接请求”授权弹窗，点击“确定”即可。

## 方案二：使用 Clash Meta 客户端 (策略组规则)

如果你希望分流更精细（例如让 YouTube 走新加坡、Netflix 走香港、普通外网走日本），推荐使用基于 Meta 内核的 Clash 客户端：

1. 启动应用后进入 **配置 (Profiles)** 页面。
2. 点击“新配置” -> 选择 **URL (从URL导入)**。
3. 填入配置名称并粘贴机场的 **Clash 订阅 URL**。
4. 点击右上角保存，下载完成后勾选并应用该配置文件。
5. 进入 **代理 (Proxy)** 页面选择 **Rule (规则模式)**。
6. 点击主页中央的 **启动** 按钮即可开启代理。

## 三、安卓手机常见问题：后台被杀与断连

由于国产安卓系统（MIUI/HyperOS、OriginOS、ColorOS、EMUI）具有极度激进的省电管理策略，很多用户锁屏 10 分钟后代理就自动断开。

### 解决方法：
1. **应用自启动管理**：在手机“应用信息”中，将客户端设置为“允许自启动”和“允许关联启动”。
2. **省电策略修改**：将电池优化策略从“智能推荐”修改为 **“无限制”** 或 **“不优化”**。
3. **任务栏上锁**：在多任务后台卡片界面，长按或下拉客户端卡片，点击“小锁”图标将其锁定在内存中。
